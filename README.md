# 🍣 Sushi Landing Page

A modern and responsive **Sushi Restaurant Landing Page** built using core web technologies.

This project focuses on creating a clean UI, responsive layout, and basic user interactions while following good frontend development practices.

---

## ✨ Features

- Fully responsive layout (mobile, tablet, desktop)
- Modern and minimal UI design
- Mobile-friendly navigation menu
- Interactive content sections
- Smooth and intuitive user experience
- Semantic and well-structured HTML

---

## 🛠️ Built With

- **HTML5**
- **CSS3**
  - Flexbox
  - Media Queries
  - CSS Variables
- **Vanilla JavaScript**
- **Git & GitHub**
